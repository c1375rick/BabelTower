Babel Tower - Deadlock 聊天翻译 Mod 安装使用说明
=================================================

本 Mod 由两部分组成:
  1. 游戏内部分(pak01_dir.vpk)—— 聊天翻译界面
  2. 本地桥(core + portable-node)—— 负责调用翻译接口(免 Key,免费)

两步都要装,缺一不可。

--------------------------------------------------
一、安装(约 3 分钟)
--------------------------------------------------

1. 把整个文件夹解压到你喜欢的位置(路径可含中文,但不要带空格,如 D:\BabelTower)

2. 安装游戏内 Mod(二选一):
   方法 A(推荐):打开 Deadlock Mod Manager,把 pak01_dir.vpk 拖进去导入
   方法 B(手动):把 pak01_dir.vpk 复制到
      <你的Steam库>\steamapps\common\Deadlock\game\citadel\addons\
      如果该目录已有同名文件,改成别的编号,如 pak25_dir.vpk

3. 启动本地桥(二选一):
   方法 A(推荐,一劳永逸):**双击 install-autostart.bat**(安装开机自启)
     之后开机自动启动桥,游戏退出桥自动关闭,什么都不用管。
     卸载自启:双击 remove-autostart.bat
   方法 B(临时):双击 StartDeadlock.bat(每次玩之前都要双击一次)

4. 启动游戏,进任意一局(训练场也行):
   - 按 Enter 打开聊天,输入 /tr 回车,打开设置面板
   - 点"测试"按钮,应显示"测试成功: 你好"
   - 点"保存",ESC 关闭面板
   - 大功告成!队友发外语消息,下方会显示金色中文译文

--------------------------------------------------
二、设置面板说明
--------------------------------------------------

  打开方式:聊天输入 /tr 回车;或聊天框右侧"译"按钮

  - 启用翻译        总开关(默认开)
  - 服务商          bing(免Key,默认)/ microsoft(Azure Key,可选)
  - API Key/区域    仅用 Microsoft 时需要填写
  - 目标语言        译文语言,下拉选择(默认简体中文)
  - 显示模式        双语(原文+译文)/ 仅译文
  - 发送前翻译      关(发原文)/ 仅译文 / 双语(原文 | 译文)
  - 发送目标语言    发送前翻译成什么语言(默认英语)
  - 超时/强制翻译   一般不用动

  所有选项点击选择,改完点"保存"生效。

--------------------------------------------------
三、常见问题
--------------------------------------------------

Q: 译文显示"本地桥未运行"?
A: 桥没启动。确认第 3 步做了:要么装了自启(重启电脑后生效),要么双击了 StartDeadlock.bat。
   也可以直接双击 restart_bridge.bat 一键重启并自动健康检查。

Q: 双击 portable-node\node.exe 只出现一个 "> " 提示符的窗口?
A: 那是 Node.js 的命令行控制台,不是启动器,直接关掉。启动桥请用
   install-autostart.bat / StartDeadlock.bat / restart_bridge.bat,不要直接双击 node.exe。

Q: 开机时弹窗 "Windows Script Host 80070002 系统找不到指定的文件"?
A: 旧版自启脚本对含中文的解压路径(如 D:\Bandizip\解压\)兼容有问题。
   重新双击 install-autostart.bat 即可修复(1.0.5 起的自启脚本自动适应任意路径),
   然后重启电脑验证。

Q: 点测试显示失败?
A: 先确认桥在运行;再确认网络能访问 bing.com(公共接口,偶尔抽风会自动重试)。
   一直失败可把服务商切到 microsoft 并填自己的 Azure Key。

Q: StartDeadlock.bat 窗口一闪就没了,或桥总是起不来?
A: 双击 run-bridge.bat(诊断启动器):它前台运行桥,报错会停在窗口里不会闪退。
   常见原因:解压不完整(core 目录缺文件)。请重新解压完整安装包,不要删除 core 里任何文件。
   崩溃详情在 logs\bridge.log,反馈问题时请附上这个文件。

Q: 游戏里没反应?
A: 确认 VPK 装到了 addons 目录且游戏完全重启过;确认 /tr 能打开设置面板。

Q: 想卸载?
A: 游戏部分:Mod Manager 里禁用/删除,或删掉 addons 里对应的 vpk。
   自启部分:powershell -ExecutionPolicy Bypass -File scripts\autostart.ps1 -Action Remove

--------------------------------------------------
四、目录结构
--------------------------------------------------

  pak01_dir.vpk          游戏内 Mod(装进 Deadlock addons)
  core\                  本地翻译桥(不要删)
  portable-node\         内置 Node.js 运行时(不要删)
  install-autostart.bat  双击安装开机自启
  remove-autostart.bat   双击卸载开机自启
  restart_bridge.bat     一键重启桥 + 健康检查(桥没起来先点它)
  run-bridge.bat         诊断启动器(报错不闪退;反馈问题前先跑它)
  StartDeadlock.bat      手动启动(桥 + 游戏)
  scripts\autostart.ps1  自启脚本(一般由上面的 bat 调用,无需手动执行)

更多说明见 README.md;源代码与构建方法见 GitHub 仓库。
