## 填写内容

- **Mod name**: `Babel Tower - Deadlock In-game Chat Translator`
- **Category / Section**: 建议选 **UI Mods**(或 Tools/Utilities,视当日分类而定)
- **Description**: 
  - 国际页面用 `description_en.md` 的内容
  - 中文补充说明用 `description_cn.md`(可合并到描述末尾,方便中文用户)

- **Tags / 标签**: 
  `deadlock ui translation translator chat language chinese english tool utility`
- **Files(必传)**:
  - `dist\BabelTower-0.1.0-win64.zip`(完整安装包,35.1 MB)
  - 建议同时注明"源代码见 GitHub:https://github.com/c1375rick/BabelTower"
- **Images(强烈建议 2-3 张)**:
  - 网页设置页截图(进游戏 /tr 用浏览器打开设置页后截图)
  - 翻译效果截图(聊天里有外语消息 + 金色译文)
