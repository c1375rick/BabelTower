# 已撤回结论账本(Corrections Ledger)

> **状态**:现行 · **适用版本**:1.2.5 · **最后核对**:2026-11-01
> **用途**:所有**被推翻、被降级、被收窄**的技术结论的唯一存放处。
> **规则**:正文里不再保留错误结论(不写删除线、不写"以前说…其实…");需要追溯时查本页。
> 新增一条 = 一次结论变更,必须同时改正文与 [README.md](README.md) 索引。

## 0. 状态定义

| 状态 | 含义 | 正文怎么写 |
| --- | --- | --- |
| **已撤回** | 结论为假,不再成立 | 直接删掉,按新结论重写 |
| **已降级** | 结论过强,收窄为条件成立 | 写收窄后的版本 |
| **已收窄** | 适用范围被限定(不是错,是过度推广) | 写明适用边界 |
| **待复核** | 有反例但本项目未复现,暂不作为事实 | 标"待复核",不得当依据 |
