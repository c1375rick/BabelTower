> **1.2.4 用户必须升级**：1.2.4 的 hash 通道出站载荷字段名错误（`target` → 应为 `targetLanguage`）导致桥读到 undefined 回退默认方向——出站翻译方向整反，中文消息被静默原样发出。

## 定位

本版集中修复底层，后续更新不再改底层内容。

## 修复清单

- **出站方向**（根因）：hash 载荷字段名 `target` → `targetLanguage`；新增端到端方向回归锁（离线模拟 T1–T5）
- **非拉丁语言扫描**：纯符号正则 `\W` 不含非 ASCII → 俄/韩/日消息被当符号静默跳过；改为 Unicode 字母判定（`\p{L}/u`）
- **配置最终一致性**：陈旧差分防护（响应落地前 rev 已推进则丢弃，防止配置回退）+ 丢弃后 2s 立即重同步（不干等 60s 兜底轮询）
- **双上下文方向新鲜度**：发送方向解析改为 convar 直读——游戏双布局（chat.xml/hudchat.xml）各持一份配置镜像，改动原来要等另一上下文 60–120s 轮询，现在跨上下文立即生效
- **潜伏 bug 根修**：`saveUiConfig()` 的 convar 写入自项目起从未生效（`json` 变量声明在 try 块内，写入点引用越界抛 ReferenceError 被空 catch 吞掉）；根修 + 幂等写（值相同不写，防事件风暴）
- **面板全局兜底**：游戏内设置面板移除后，主文件引用的 `fieldValue` / `labelFor` 等面板函数悬空（legacy 自定义目标配置下会让消息发不出去）；已在主文件内兜底
- **写入来源审计**迁到 HTTP POST 写分支（原位置 `req` 不在作用域，是死代码）

## 已知项（不影响功能，后续版本处理）
